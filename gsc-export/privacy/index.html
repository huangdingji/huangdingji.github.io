Data use disclosure

Privacy Policy

Effective: September 27, 2026

Purpose of the tool

qzjy GSC Export is a private reporting utility used by the owner of qzjy.store to retrieve and analyze the site's Google Search Console performance data.

Google data accessed

The tool requests the Google Search Console read-only scope. It may access Search Console properties available to the authorized Google account and retrieve performance information such as queries, pages, dates, countries, devices, clicks, impressions, click-through rate, and average position.

How data is used

Retrieved data is used only for the owner's internal website performance reporting and search optimization decisions. The tool does not change Search Console settings, submit URLs, edit website content, or request access to unrelated Google services.

Storage and sharing

  • OAuth credentials and exported reports are stored in the owner's controlled local working environment.
  • Google user data is not sold, rented, used for advertising, or shared with unrelated third parties.
  • Access is limited to the owner and tools acting on the owner's instructions.

Retention and deletion

Local credentials and exported reports are retained only as needed for ongoing reporting. The owner may delete local credentials or reports at any time and may revoke the application's Google access from the Google Account permissions page.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
